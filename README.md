# 🌆 Overview

Urban mobility is influenced by multiple interconnected factors such as traffic, public transportation, metro infrastructure, weather, geography, and population.

The **Smart City Mobility Intelligence Platform** brings these different data sources together into an interactive **Power BI** environment.

The platform currently covers:

- 🚗 Traffic
- 🚌 Bus transportation
- 🚇 Metro networks
- 🚲 Bike sharing
- 🌦️ Weather
- 👥 Demographics
- 📍 Mobility infrastructure

The Power BI dashboard provides an integrated view of mobility patterns across **Delhi and Bengaluru**.

---

# 🎯 Objectives

The main objectives of the project are:

- Integrate multiple urban mobility datasets
- Analyze traffic conditions and transportation performance
- Explore public transportation networks
- Analyze bus and metro infrastructure
- Visualize mobility data geographically
- Examine weather-related mobility variables
- Develop meaningful KPIs using DAX
- Provide interactive dashboards for mobility analysis
- Enable comparison of mobility characteristics between Delhi and Bengaluru
